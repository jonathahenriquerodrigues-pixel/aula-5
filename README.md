# Sistema de Gerenciamento Acadêmico — Aula 5

Protótipo em HTML e CSS com painel inicial, listagens e formulários de alunos, cursos, matrículas e usuários. A folha de estilo está em `css/style.css`.

## Como abrir

Abra [index.html](index.html) no navegador. Use o menu para visitar as listagens e os links de cadastro para conhecer os formulários. Os dados são exemplos estáticos e o botão Salvar permanece desativado nesta etapa.
